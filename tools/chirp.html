Hero Voice Studio

Records all six Empire Origins heroes with Google's Chirp 3 HD voices. All six heroes fit inside Google's free allowance. Your API key stays in this browser tab: it is only sent to Google and is never saved.

1 · Connect

In console.cloud.google.com: turn on the Cloud Text-to-Speech API, then APIs & Services → Credentials → Create credentials → API key.

2 · Pick each hero's voice

3 · Record

About 330 lines per hero. Keep this tab open; if it stops, press Record again and it carries on where it left off.

Not started.

4 · Send them to Claude

Download each hero's file and attach all six to your chat with Claude. Claude puts them into the game.
