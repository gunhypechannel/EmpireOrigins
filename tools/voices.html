Hero Voice Studio

Records all six Empire Origins heroes with ElevenLabs voices. Your API key stays in this browser tab: it is only sent to ElevenLabs and is never saved.

1 · Connect

Get the key in ElevenLabs → Developers → API Keys (give it Text to Speech and Voices access).

2 · Pick each hero's voice

3 · Record

About 330 lines per hero. Keep this tab open; if it stops, press Record again and it carries on where it left off.

Not started.

4 · Send them to Claude

Download each hero's file and attach all six to your chat with Claude. Claude puts them into the game.
